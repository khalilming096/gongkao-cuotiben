# 公考错题本

按「模块 → 题型 → 子类 → 知识点 → 错误记录」记录公考错题的次数与时间，勾选一次即累计一次错误。

**定位**：不存题干、不存解析，只记「哪个知识点在反复错、错了几次、什么时候错」。题目本身交给「错题复盘」的题库（藏题，18,011 题）。

| 文件 / 目录 | 说明 |
| --- | --- |
| `index.html` | **网页版（当前最新，v3）**，单文件，浏览器打开即用 |
| `catalog.json` | 分类表，由题库自动生成，供网页版内嵌使用 |
| `tools/gen_catalog.py` | 从题库 `source` 路径重新生成分类表 |
| `tools/inject_catalog.py` | 把 `catalog.json` 注入 `index.html` |
| `公考错题本-v3.0.0.apk` | 安卓安装包（v3.0），分类与网页版同源，都读 `catalog.json` |

> 安卓端已同步题库分类：`catalog.json` 打包在 `assets` 里，App 启动时读取。**备份导出/导入目前只有网页版有**，安卓端待补。安装包体积大，不入库，只保留在本地目录。

## 一、分类体系：由题库生成，不手写

分类不再是拍脑袋定的，而是扫描题库里 18,011 道题的 `source` 路径（如 `判断推理/…/图形推理/数量规律-面/10204456 xxx.md`）统计出来的：

| 模块 | 题量 | 题型 | 子类 |
| --- | --- | --- | --- |
| 言语理解 | 6,762 | 3 | 17 |
| 判断推理 | 7,728 | 5 | 28 |
| 资料分析 | 3,521 | 6 | 33 |
| 合计 | 18,011 | 14 | 78 |

各题型的子类（括号内为题量，只列前几项）：

- **片段阅读**（2963）：中心理解 1600、细节判断 918、标题填入 253、词句理解 170、其他
- **逻辑填空**（2690）：实词填空 990、混搭填空 879、成语填空 744、语境分析 51、词的辨析 26
- **语句表达**（1109）：语句填空 386、语句排序 355、下文推断 186、病句辨析 110、语句衔接 32…
- **增长**（1198）：一般增长率比较 275、一般增长率计算 186、增长量计算 181…（共 12 类）
- **比重**（787）：现期比重 471、基期比重 104、统计图选择 83、两期比重差 73…
- **综合分析**（612）：选是型 434、选非型 178
- **简单计算**（395）：简单加减计算 193、排序比较 178、直接找数 23
- **平均数**（284）：现期平均数 189、平均数增长率 36、基期平均数 30…
- **倍数**（245）：现期倍数 165、基期倍数 38、现期倍数比较 29、现期追赶 13
- **逻辑判断**（2482）：加强削弱 1019、分析推理 405、翻译推理 314、前提假设 210…（共 11 类）
- **图形推理**（1873）：数量规律 553、立体图形 381、样式规律 334、位置规律 324、属性规律 279
- **类比推理**（1640）：对应关系 756、逻辑关系 516、语义关系 259、语法关系 84、范围关系 25
- **定义判断**（1602）：单定义 1262、多定义 340
- **科学推理**（131）：物理 81、化学 27、物理推理 14、其他

**两条生成规则**：

1. 题量 < 10 的子类合并为「其他」，避免筛选条被 1 题的小类塞满（原始有 300 多个细分）；
2. 每个子类保留题库里最常见的细分名（如「中心理解」下面是关联词-对策 396、主题词 362、关联词-转折 285），新增知识点时可以一键点选，不用自己想名字。

政治理论、常识两个模块题库里没有，仍直接挂知识点。

## 二、错因按题型区分

错因不是一套通用标签，而是「题型专属 + 通用兜底」两层：

- **专属错因**（蓝色）：该题型最典型的失分动作，由 `gen_catalog.py` 里的 `TOPIC_ERRORS` 定义，随分类表一起输出；
- **通用错因**（灰色）：审题不清、时间不够、蒙错、知识点遗忘，任何题型都可能用到。

| 题型 | 专属错因 |
| --- | --- |
| 片段阅读 | 没抓中心句、以偏概全、偷换概念、答非所问、无中生有 |
| 逻辑填空 | 呼应点找错、词义侧重混、搭配对象错、褒贬误用、望文生义 |
| 语句表达 | 首尾句判错、话题不统一、关联词错位、语序判错 |
| 图形推理 | 规律没看出、数量数错、元素组成判错、空间想不出 |
| 定义判断 | 要素漏抓、主体范围错、设问看反 |
| 类比推理 | 一级关系判错、二级辨析漏、词性不一致 |
| 逻辑判断 | 论点论据找错、削弱加强弄反、翻译规则记错、力度比较错 |
| 科学推理 | 公式记错、单位换算错、概念混淆 |
| 增长 | 公式混淆、时间定位错、截位位数错、增长量与率混 |
| 比重 | 部分整体找错、基期现期搞混、两期方向判错 |
| 平均数 | 分子分母找错、增长率与量混 |
| 倍数 | 倍数与多几倍混、基期现期找错 |
| 简单计算 | 加减错位、排序看漏、单位不统一 |
| 综合分析 | 选项顺序乱、漏看「不正确」、中途放弃 |

政治理论、常识没有题库分类，用模块级错因（时政记混／法律条文混等）+ 通用兜底。

两处示例文案也随层级变化：

- **错因输入框**提示该题型的典型错法，如片段阅读是「只看了首句，没发现转折后的句子才是重点」，增长是「把增长率当成增长量算」；
- **名称输入框**提示该子类在题库里最常见的细分名，如「中心理解」下是「关联词-对策」，「常识」下是「二十四节气顺序」。

## 三、功能

| 功能 | 位置 |
| --- | --- |
| 主界面五个固定模块，显示我的知识点数与题库规模 | 主页 |

## 四、数据结构（v3）

```js
point  = {id, mod, g, s, name, reason, count, created}
record = {id, pid, ts, n: 备注, q: 题库题号}
```

- `mod`：`zzll` / `cs` / `yy` / `pd` / `zl`
- `g`：题型 key，如 `pdyy`（片段阅读）、`zz`（增长）；空串表示未归类
- `s`：子类名，如 `中心理解`、`一般增长率计算`
- `count` 与该知识点的记录条数保持一致（勾选、撤销、删除都在同一步里同步）
- 旧数据（v1/v2）首次打开会自动迁移：英文子类 key 按映射表换成题库分类，映射不到的归入「未归类」，可在题型列表底部进入重新归类

## 五、备份与恢复

- **导出**：说明弹窗 → 导出备份，下载 `cuotiben-backup-YYYYMMDD.json`，结构 `{app, version, points, records}`
- **导入**：说明弹窗 → 导入备份，按「模块 + 题型 + 子类 + 名称」识别同一个知识点
  - 重复的知识点：次数取较大值，错因取新值，创建时间取较早
  - 记录按时间戳去重，不会重复累加
  - 导入只增不减，不会覆盖现存数据

## 六、题库更新后重新生成分类

```bash
python tools/gen_catalog.py      # 读题库 source 路径 → catalog.json
python tools/inject_catalog.py   # 把 catalog.json 注入 index.html
```

`gen_catalog.py` 里 `MIN_SUB = 10` 控制长尾合并阈值，`TOPIC_KEYS` 保证题型 key 稳定（旧数据迁移依赖它）。
